# Security Policy

## Supported versions

No version is supported while FlowBaton is pre-alpha. A support window will be
published with the first signed public release.

## Reporting

Report suspected vulnerabilities through GitHub private vulnerability reporting
for the public `larchwave/flowbaton` repository. Do not open a public issue for an
unpatched vulnerability. Include the affected version or commit, impact,
reproduction steps, and any proposed mitigation.

Never include credentials, device data, recordings, or unredacted debug artifacts in an issue or report. The project does not promise a bounty or a response SLA before v1.
